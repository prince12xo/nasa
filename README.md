🚀 Overview
PrepOS is a high-performance, single-page web OS designed to organize, track, and optimize intense STEM preparation. Built with a space nebula aesthetic, high-contrast readability, and Italian serif typography, it replaces static task managers with dynamic telemetry modules, countdown engines, focus tools, and client-side AI diagnostics.
✨ Key Features & Architecture
1. ⏱️ Mission Countdown & Focus Engine
Exam Telemetry Counter: Live real-time countdown to target competitive examination dates.
Integrated Focus Stopwatch: Precision timer for deep work sessions to track elapsed study durations.
2. 📋 Interactive Syllabus Tracker
CBSE Class 12th & Competitive Mapping: Structured checklists covering Physics, Chemistry, and Mathematics.
High-Yield Filtering: Instant toggles to filter chapters by high-weightage topics and completion status.
State Persistence: Preserves progress locally across browser sessions.
3. 🤖 Dynamic Client-Side AI Schedule Generator
Algorithmic Study Plans: Generates targeted daily revision routines based on weak areas and remaining time without requiring external server dependencies.
4. 🛠️ Error Log & Diagnostic Engine
Mistake Tracking: Log mock-test errors, categorize failure modes (conceptual vs. calculation), and auto-generate corrective action steps.
🛠️ Tech Stack
Frontend: HTML5, CSS3 (CSS Variables, Flexbox/Grid, Dark Space Nebula styling)
Logic: Vanilla JavaScript (app.js — ES6+)
Hosting: Render Static Site Services
Version Control & Tracking: Git / GitHub, Hackatime / WakaTime telemetry integration
